竞价承接强度框架（情绪抓妖股）

核心问题：9:25 集合竞价定盘的那一刻，怎么判断资金承接意愿强不强、今天还能不能继续涨停？

答案：看 竞价涨幅（开在哪） + 竞价量/竞价换手（承接了多少货） + 全天换手（换手够不够充分） 三者组合。

数据源现状（重要）

数据 可得性 来源
竞价涨幅（开盘价-昨收） ✅ 免费可得 日K开盘价即可，腾讯/东财都行
竞价量 / 竞价换手率 ❌ 历史数据免费接口拿不到 东财/腾讯/同花顺均无历史竞价成交量，只能实时抓
全天换手率 ✅ 免费可得 腾讯 qt.gtimg.cn / 东财实时

结论：历史竞价量无法回溯，框架采用 每日 9:26 实时抓竞价 + 全天换手率做代理校验 两条腿走路。

系统已用 auction_sniffer.py 自动抓取：5板以上妖股 + 低位涨停自动进观察池，工作日 9:26 定时任务抓竞价快照。

承接强度分级（由参考表归纳）

级别 竞价涨幅 全天换手 含义 操作倾向
🔴 一字缩量（最强承接） ≥+9.5% 一字 <5% 卖盘锁死、无货可接，一致性强 排队打板，开板就是机会
🟠 高开秒板（活跃承接） +5%~9% 5%~15% 竞价抢筹明显，开盘秒封 强承接，可打
🟡 高开换手（分歧承接） +1%~5% 15%~25% 有人卖有人接，换手充分 看换手位置：低位健康、高位警惕
🟢 平/低开换手（弱转强/反包） <+1% 甚至低开 视情况 竞价没人抢，靠盘中情绪拉板 只认低开巨量反包（如哈药07-21），缩量低开板弱

关键规则（实战信号）

  1. 一字缩量 = 最强的承接：百花 08-04(2.8%)、08-10(1.3%)、哈药 08-10(5.2%) 续板全是竞价一字+低换手。换手越低越难买到，说明根本没人卖。
  2. 高位竞价涨幅从一字回落 + 放量 = 断板前兆：

    3. - 百花 08-12：竞价 +10%→+4.94%、全天换手 34.4% → 次日断板

    - 哈药 08-11：竞价 +10%→+3.19%、换手 27% → 次日未封

    - 信号：5板以上妖股竞价涨幅跌破 +5% 且全天换手>25% → 分歧转弱，次日大概率断板，减仓/回避。

    1. 低开巨量反包 = 主力强做多：哈药 07-21 竞价 -7.91%、换手 28.9%，盘中从-8%拉到涨停，是分歧中的主力吸筹反包，次日仍有溢价。但只适合已充分换手的中位票，高位低开=出货。
    2. 竞价换手率 > 全天换手的量级对照：竞价换手率 2%~5% 视为正常承接（对应全天 5%~15%）；竞价换手 10%+ 属异常放量，一字板里的巨量（百花 08-06 全天32.7%）说明开板换手、分歧加大。

      3. 每日自动工作流

      每日20:00 daily_scan 运行
  └─ 同花顺涨停池 → 5板以上妖股 + 低位(≤2板)涨停 → 写入 engine/output/auction_watch.txt
每日9:26 定时任务 AuctionSniff9x25
  └─ auction_sniffer.py 实时抓竞价(涨幅/量/换手) → engine/output/auction_log.csv
盘中/盘后
  └─ 对照承接分级判断：低位涨停承接强→可接力；妖股竞价破位放量→避雷

      观察池文件 auction_watch.txt 每行格式：代码,名称,secid,标签，标签 YAOGU5/6/7（板数≥5）、LOW（低位）、REF（参考票）。三只参考票永久保留。

      数据局限与下一步

      • 历史竞价量免费接口拿不到，参考表的"竞价换手"是实时抓取后的次日回看，需累积。
      • 已建好 auction_log.csv 每日累积，运行一周后可对"竞价涨幅×换手→次日是否续板"做命中率回测。
      • 后续新增 5板+ 妖股会自动进观察池，无需手动维护。
